# Conteúdo
Arquivos *JSON* de planejamento do deploy e da reversão

## Nome dos Arquivos
```
Plan_[origem]_Deploy

Onde: "Plan" -> Prefixo (fixo)
      [origem]-> Nome da branch ou da tag de origem dos códigos-fonte

Exemplos: Plan_feature_FP-5555_Deploy.json
```
Detalhe: **Cada operação terá sempre dois arquivos: um para Deploy e outro para Revert**
